# 首版软件验证记录

目标为 M5Stack StickS3。固件源码版本为 `fdba170`。本轮完成软件验收，设备烧录与实机验收留待下一阶段。

| 验证 | 结果 |
|---|---|
| 主机规则用例 `tests/rules.cpp` | 通过。包括四类动作、反向回拉、圈后前推、发声节奏、精通、奖励、单机与合作战斗，以及 NEC 完整帧和非法帧。 |
| 双端协议用例 `tests/link.cpp` | 通过。包括房间握手、过期快照、重复结算、格挡与未中、应用层确认、合作通关和格挡联动去重。 |
| 目标构建 `.\stick.cmd run` | 成功生成 ESP32-S3 的 `firmware.elf` 与 `firmware.bin`。PlatformIO espressif32 6.12.0，M5Unified 0.3.0，M5GFX 0.3.0，M5PM1 1.0.7。 |
| 链接器报告 | 应用 Flash 占用 1,264,609 / 3,342,336 字节（37.8%），静态 RAM 占用 48,972 / 327,680 字节（14.9%）。 |

设备端仍须按验收计划验证红外命中距离和角度、功放开关延迟、动作识别率、声音阈值、断电存档和具体灯具响应。主机测试中的红外和无线事件为受控输入。
