# StickS3 试玩与复验

## 本地复验

在工程目录运行 `.\stick.cmd run`。首次搭建环境运行 `.\stick.cmd setup`。两个入口都以构建结束。板型采用 M5Stack 的 PlatformIO 参数，程序启动时再用 M5Unified 检查实际板型。烧录安排在硬件验证阶段。

主机用例直接编译固件共用的头文件。在有 GCC 的终端中执行以下命令。

```sh
g++ -std=c++11 -Wall -Wextra -Werror tests/rules.cpp -o rules-test
./rules-test
g++ -std=c++11 -Wall -Wextra -Werror tests/link.cpp -o link-test
./link-test
```

## 拿起魔杖之后

- 巢穴中点 B 轮换入口，点 A 进入。在任意活动中长按 B 约 0.75 秒回巢。小龙闲置约 20 秒后入睡，可摇醒。
- 训练或战斗时点 B 选法术。让杖保持稳定，按住 A 后横挥、沿杖身前推、绕长轴翻腕或在面前画圈，看到“可释放”后松手。圈后前推可以释放蓄力冰箭。
- 对麦克风平稳发声或分拍发声可积攒能量，符文外环亮起时释放有节奏加成。连续成功释放也有加成。同一法术训练三次获得精通，之后该技能蓄力得到额外加成。
- 试炼中查看敌相并选择法术。双人游玩时，一台创建决斗或双人副本，另一台寻找房间，用房间号核对后按 A 加入。建房者先手。决斗时对方魔杖提示“静默判定”后保持瞄准，守方可提前翻腕，副本则轮流攻击同一个 Boss。
- 机关页点 B 依次轮换三个学习槽、三个施放槽和三个挑战槽。点 A 进入当前操作。学习时对准 StickS3 按一下遥控器键；兼容范围是 38 kHz 标准与扩展地址 NEC 完整帧。挑战时收到对应遥控键可为小龙增加经验。
- 打赢 Boss 后按 A 进入奖励页，点 B 选择已绑定槽，按住 A 横挥或前推再松开，向灯发出对应指令。现实符文作为永久解锁保留，之后也可从机关页施放。
- 演示格挡联动时，在守方的机关页继续点 B 到目标槽的“格挡联动”，点 A 后按住 A 挥杖再松开以启用。决斗中成功挡下火斩后，守方在无线结算后发出一次已绑定灯光指令。选择“解除联动”可关闭，重启或重新绑定该槽的其他指令也会关闭。摆位时需同时考虑两根魔杖交手和守方魔杖照到灯具接收窗的方向。

## 设备验收记录

使用电池或 USB 为 StickS3 供电。固件启用板载红外所需的 EXT_5V 输出，Grove 与 Hat EXT_5V 应保持无外部供电。先让两台红外窗口正对并相距至少 30 cm。每项实测记录固件版本、姿势、距离、角度、环境光、成功次数及总次数。[StickS3 官方硬件说明](https://docs.m5stack.com/zh_CN/core/StickS3)

决斗接收器启动 35 ms 后通告就绪，此后保留 1.8 s 接收窗口。攻方就绪后每 160 ms 重发同一令牌，直至结算。房主最多等就绪 2.3 s，首次就绪后另留 650 ms 用于回报。未命中时看守方屏幕第二行，可区分未收到红外、波形不完整和收到其他码。实测可先固定两台朝向、双方各释放十次，再遮挡复测并记录结果。[完整验收计划](acceptance.md)
