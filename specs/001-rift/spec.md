# 《裂隙 RIFT》首版规格

本规格以一只常驻小龙、四种动作、一个 Boss、双人决斗和三个现实机关为发布边界。两个玩家可共同挑战同一个 Boss。三人以上的职业分工、浏览器观战、交换精灵、素材包及编辑器属于后续版本。

| 编号 | 玩家可观察到的行为 | 验收场景 |
|---|---|---|
| R1 | 龙会呼吸、休眠，被按键或摇晃唤醒。训练使对应法术获得精通，战斗与机关共用同一份成长存档。 | 训练、击败 Boss、重新启动，检查精通、经验、称号、外观和现实符文。 |
| R2 | B 选择技能，按住 A 做动作，松开 A 施法。横挥为火斩，前推为冰箭，翻腕为护盾，绕圈为治愈。圈与声音可额外蓄能，连续动作可以连招。 | 静止或做错动作释放时无效。相同动作下持续发声、分拍发声能改变能量。圈后前推仍可释放冰箭。 |
| R3 | 单机试炼中 Boss 预告属性并反击，护盾、治疗、克制与节拍影响结果。胜利后可选取已绑定机关并挥杖确认。 | 胜负均能返回巢穴，只有胜利发奖。已学遥控器也能参与单机机关挑战。 |
| R4 | 两台同频道设备分别建房、加入，轮流攻击。攻击方准备，守方可提前翻腕，红外匹配当前施法才命中。双方显示一致的血量、格挡、反击与输赢。 | 遮住红外时即使无线畅通也判未中。重复包不重复扣血。对端离开后可退出或重新建房。 |
| R5 | 双人共斗轮流向同一个 Boss 施法，治疗惠及队友，双方领取各自存档中的通关奖励。 | 两台显示相同 Boss 血量，最后一击结算一次。 |
| R6 | 三个独立槽学习、保存并重放兼容的 38 kHz NEC 遥控器完整帧。学习有超时，失败保留旧槽。 | 分别绑定三个按键，重启，逐个选择并扬杖执行。游戏红外帧及重复短码不能写入机关槽。 |
| R7 | 红外使用 ESP-IDF RMT。接收时释放扬声器并关闭功放，离开接收窗口才允许播放。屏幕、声音能区分蓄力、命中、格挡、冰冻和通关。 | 双机测 GPIO42 接收窗口、功放切换与音效顺序，记录实际成功率。 |

## 验证边界

R6 的决斗演示场景使用同一组机关槽。获得现实符文后，玩家可以主动选择一个槽，挥杖把它绑定到本次开机期间的成功格挡。默认关闭，可随时解除。格挡者仅在收到已结算的回合快照、关闭红外接收后发出一次灯光指令；未命中或重复快照均不触发。

主机测试使用可重复的动作轨迹、声音采样结果、红外脉冲和网络事件。固件链接使用现有 PlatformIO 环境。距离、角度、声压阈值、动作轴向和切换延迟必须在 StickS3 上标定。本轮交付到构建，设备烧录另行安排。
